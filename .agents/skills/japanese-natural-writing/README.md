# japanese-natural-writing

Geminiに自然な日本語への改稿を依頼し、Codexが原文との意味・トーンのずれを照合するスキルです。

## 使い方

展開した `japanese-natural-writing` フォルダーを、利用環境のスキル配置先に置いてください。`SKILL.md` がスキルの入口です。依頼例：

> $japanese-natural-writing を使って、次の文章を自然な日本語に推敲してください。

Antigravity CLI（`agy`）と、指定モデル `gemini-3.8-flash-high` を利用できる環境が別途必要です。CLIの導入・認証・モデルの提供状況は各利用者の環境で確認してください。実行条件は [実行契約](references/07-execution-contract.md) を参照してください。

## 収録範囲

スキル本体、プロンプト、レビュー基準、汎用のJSON入力例、公開参考資料へのリンクのみを収録しています。入力例は実際のメールの引用ではありません。

個人用パス、個人の文体サンプル、原稿、推敲結果、評価データ・実行ログ、開発履歴、認証情報、CLI本体は含めていません。文章は実行時に利用者の環境からGeminiへ送られるため、送信してよい文章だけを入力してください。
